# 제출 문서

## 1. 요구사항 해석

- 합의문 요약 (전체는 docs/agreement.md)
- 만든 것과 만들지 않은 것

## 2. 설계와 주요 판단

- 설계 단계별 결정과 근거 (데이터 모델, API, 화면, 핵심 로직)
- 트레이드오프와 위험 요소

## 3. AI 활용 방식

- 모델별 역할 분담, 사용한 Skill과 도구, 선택 이유
- 작업 체계: 단계별 진행, 세션 전환, 리뷰 → 설명 → 확인 → 커밋 루프
- AI 제안을 수정한 사례 (docs/DECISIONS.md 기반)

## 4. 검증 방법과 결과

- 성공 기준별 충족 여부 (docs/verification.md 기반)
- 테스트, 코드 리뷰(docs/reviews/), Playwright 확인과 사용자 검수

## 5. 사용한 공개 자료

- 사용한 하네스 문서, 외부 Skill 출처

## 6. 남은 한계와 개선 방향

- 미구현, 미검증, 제외한 항목과 그 이유
- 알려진 위험과 개선 방향

## 7. 실행 방법

- 필요 환경, 실행 명령, 접속 포트와 경로, 테스트 명령
