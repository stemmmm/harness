# 합의문 작성

## 입력

- README와 과제 안내
- 제공 데이터와 데이터 설명 문서 (있는 경우)
- 사용자가 전달한 실무자 답변 (실무자 대화는 직접 볼 수 없음)

## 절차

- 제공 데이터가 있으면 질문을 만들기 전에 먼저 살펴봄 (데이터 파일은 수정하지 않고 읽기만)
  - 파일별 행 수, 열, 빈 값, 중복, 형식이 어긋난 값
  - 파일 사이의 ID 참조가 깨진 곳, 같은 정보가 파일마다 다르게 적힌 곳
  - 데이터 설명 문서와 실제 값이 다른 곳, 상식에서 벗어난 값이나 분포
- README와 데이터 확인 결과를 기준으로 templates/agreement.md 형식의 docs/agreement.md 초안 작성, 데이터에서 발견한 사실은 근거(파일, 값, 건수)와 함께 데이터 확인 결과에 기록
- README나 실무자 답변에 근거가 없는 항목은 채우지 않고 "확인 필요"로 표시
- 확인 필요 항목을 실무자에게 물을 질문 목록으로 제시
  - 사소한 사실 확인에서 우선순위, 경계 조건 순서로
  - "무엇을 하면 되나요" 같은 포괄적인 질문 대신 구체적인 질문
  - 데이터에서 발견한 차이나 해석이 필요한 값은 근거(파일, 값, 건수)를 붙여 질문
  - 비기능 요구사항(사용자 수, 데이터 규모, 성능, 보안)도 필요한 경우 질문에 포함
- 사용자가 실무자 답변을 전달하면 합의문을 갱신하고, 확인 필요가 남아 있으면 반복
- 사용자가 합의 완료를 알리면 종료
- 이후 요구사항이 바뀌면 변경 이력에 변경 내용과 근거를 추가하고 갱신
