# 제출 문서 작성

## 입력

- docs/의 기록: agreement.md, PLAN.md, DECISIONS.md, verification.md, reviews/, screenshots/
- git log
- 테스트 실행 결과

## 절차

- 과제 안내에 문서명과 형식 지정이 있으면 그것을 우선, 없으면 templates/SUBMISSION.md 형식으로 docs/SUBMISSION.md 작성
- 사용한 공개 자료에는 사용한 하네스 문서(AGENTS.md, WORKFLOW.md, SETUP.md, Skill)와 외부 Skill 출처(각 Skill 폴더의 SOURCE.md) 포함
- 문서의 모든 주장을 실제 코드, 커밋, 테스트 결과와 대조, 확인되지 않는 내용은 삭제하거나 미검증으로 표시
- 대조 결과 불일치 항목을 따로 보고
- 초안을 사용자에게 보여주고 확인받은 뒤 확정
